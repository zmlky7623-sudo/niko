# NIKO AI — نسخه آزمایشی اندروید ۰٫۱

این پروژه یک نمونه اولیه قابل توسعه برای دستیار صوتی فارسی نیکو است.

## امکانات فعلی
- رابط کاربری مشکی و قرمز
- دریافت فرمان صوتی با زبان `fa-IR` از طریق سرویس تشخیص گفتار نصب‌شده روی گوشی
- پاسخ صوتی با موتور Text-to-Speech گوشی (در صورت نصب بودن صدای فارسی)
- اعلام ساعت و تاریخ
- جست‌وجوی مخاطب در دفترچه تلفن
- نمایش تأیید قبل از تماس

## محدودیت‌های مهم این نسخه
- این نسخه همیشه در پس‌زمینه به کلمه «Niko» گوش نمی‌دهد؛ برای شروع مکالمه باید دکمه میکروفون را بزنی.
- تشخیص گفتار ممکن است به اینترنت یا سرویس Google وابسته باشد؛ آفلاین بودن آن به پشتیبانی سرویس گفتار گوشی بستگی دارد.
- موتور اختصاصی بیدارباش آفلاین، مدل زبانی محلی، آب‌وهوای زنده، خواندن/پاسخ پیام‌ها و مدیریت اعلان‌ها هنوز پیاده‌سازی نشده‌اند.
- تماس فقط پس از تأیید روی صفحه انجام می‌شود. در صورت ندادن مجوز تماس، شماره‌گیر باز می‌شود.
- پیامک خودکار ارسال نمی‌شود؛ نسخه بعدی می‌تواند متن را آماده و برنامه پیام‌رسان را برای تأیید کاربر باز کند.

## ساخت APK
پروژه را در Android Studio باز کن، Gradle Sync را انجام بده و از مسیر:
`Build > Build Bundle(s) / APK(s) > Build APK(s)`
فایل APK را بساز.

نیازمندی‌ها: Android Studio، JDK 17 و Android SDK Platform 35.

## ساخت APK بدون لپ‌تاپ (با GitHub Actions)
1. فایل ZIP را از حالت فشرده خارج کن.
2. پوشه‌های داخل پروژه را در یک مخزن GitHub جدید آپلود کن (ساختار پوشه‌ها باید حفظ شود).
3. وارد زبانه Actions مخزن شو و اجرای `Build NIKO AI APK` را انتخاب کن؛ اگر خودکار شروع نشد، روی `Run workflow` بزن.
4. پس از پایان موفق، در بخش Artifacts فایل `NIKO-AI-debug-apk` را دانلود و روی گوشی نصب کن.


## شنود پس‌زمینه و کلمه بیدارباش (آزمایشی)
در صفحه اصلی دکمه «فعال‌کردن شنود پس‌زمینه» سرویس foreground میکروفون را شروع می‌کند. هنگام فعال بودن، اعلان دائمی NIKO نمایش داده می‌شود و با «توقف شنود» می‌توان آن را خاموش کرد. سرویس از تشخیص گفتار روی‌دستگاه اندروید در نسخه‌های پشتیبانی‌شده استفاده می‌کند و عبارت «نیکو» را بررسی می‌کند؛ فرمان‌های ساده ساعت، تاریخ و باتری را می‌تواند با صدا پاسخ دهد.

محدودیت‌های مهم:
- این پیاده‌سازی یک مدل اختصاصی wake-word نیست؛ از SpeechRecognizer سیستم استفاده می‌کند و ممکن است بسته زبان فارسی آفلاین روی دستگاه موجود نباشد یا موتور تشخیص، شنود پیوسته را پشتیبانی نکند.
- برای تشخیص آفلاین واقعی، Android 12+ و `isOnDeviceRecognitionAvailable` لازم است؛ حتی در این حالت باید زبان فارسی آفلاین در گوشی پشتیبانی و نصب شده باشد.
- سرویس میکروفون باید وقتی برنامه روی صفحه و در حال استفاده است توسط کاربر شروع شود. اندروید ممکن است شروع خودکار از پس‌زمینه، پس از خاموشی/راه‌اندازی مجدد، یا در برخی حالت‌های ذخیره باتری را محدود کند.
- شنود پیوسته باتری مصرف می‌کند و اعلان دائمی دارد. نشانگر میکروفون/حریم خصوصی اندروید فعال خواهد بود.
- این نسخه هنوز فرمان‌های پیچیده، تماس/پیام از پس‌زمینه، یا مکالمه عمومی آفلاین را انجام نمی‌دهد.
